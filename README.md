# CodexBar personal releases

Downloads and signed Sparkle updates for the customized CodexBar Control Center, usage statistics, and quota timeline.

Find available builds on the [Releases page](https://github.com/IXSUAREZ/CodexBar-Releases/releases). In an installed fork build, use **About → Check for Updates** or **More → Check for Updates** to install the latest published version.

Application source is maintained separately. Personal builds are ad-hoc code signed and are not Apple notarized; the app verifies the signed update feed and download before installation.
